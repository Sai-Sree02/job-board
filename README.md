# HireAI - AI Powered Job Board

## Overview
HireAI is a modern AI-powered job board platform built using React, Vite, Supabase, and AI-assisted development with Bolt.new.

## Features

### Candidate Features
- User Registration & Login
- Browse Jobs
- Save Jobs
- Apply for Jobs
- Application Tracking
- Resume Upload
- Profile Management

### Employer Features
- Employer Registration
- Create Job Listings
- Edit Job Listings
- Delete Job Listings
- View Applicants
- Manage Posted Jobs

### AI Features
- Resume Analyzer
- Cover Letter Generator
- AI Job Matching

### Database
Powered by Supabase

Tables:
- profiles
- jobs
- applications
- saved_jobs

### Authentication
- Email / Password Authentication
- Role Based Access Control

### Deployment
Frontend: Vercel
Database: Supabase
Repository: GitHub

## Technology Stack

- React
- Vite
- JavaScript
- Tailwind CSS
- Supabase
- GitHub Actions
- Vercel

## CI/CD Pipeline
